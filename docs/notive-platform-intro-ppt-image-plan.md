# Notive Platform Intro PPT Image Plan

# 1. 목적

이 문서는 Notive 플랫폼을 회사 내부 직원들에게 소개하기 위한 PPT형 이미지 제작 설계안이다.

대상은 개발자가 아닌 여러 직무의 직원이며, 목표는 기술 구조 설명이 아니라 Notive가 왜 필요하고 어떻게 쓰이는지 쉽게 이해시키는 것이다.

핵심 메시지:

> Notive는 흩어진 업무 맥락을 모아, AI가 회사 문서 초안을 만들고 지식으로 재사용하게 돕는 플랫폼입니다.

# 2. 발표 톤

* 쉽고 직관적인 업무 도구 소개
* 기술 용어 최소화
* 한 장당 핵심 문장 1개
* 보조 설명은 3개 이하
* 문서, 업무 기록, 검색, AI, 권한을 반복 시각 요소로 사용
* 밝은 배경과 초록/청록 포인트 컬러 사용

# 3. 전체 구성

## Slide 1. 표지

제목:

`Notive`

부제:

`업무 맥락을 문서와 지식으로 바꾸는 AI 업무 플랫폼`

이미지 방향:

노트, 문서, 검색창, AI 아이콘이 하나의 업무 대시보드로 모이는 장면.

## Slide 2. 우리가 겪는 문제

핵심 문장:

`업무 정보는 많지만, 문서를 만들 때마다 다시 찾고 정리합니다.`

포인트:

* 문서가 여러 곳에 흩어짐
* 회의, To-do, 업무 기록이 분리됨
* 보고서 작성이 반복됨

이미지 방향:

여러 앱과 문서 조각이 흩어져 있는 직장인 업무 화면.

## Slide 3. Notive가 해결하는 방식

핵심 문장:

`Notive는 흩어진 업무 맥락을 한곳에 모아 문서 작성에 활용합니다.`

포인트:

* 문서
* 업무 기록
* To-do
* 템플릿
* 검색

이미지 방향:

여러 정보 조각이 Notive 중앙 허브로 모이는 인포그래픽.

## Slide 4. 한 문장으로 보는 Notive

핵심 문장:

`AI 문서 생성기 + 사내 문서함 + 업무 기록 허브 + 지식 검색`

이미지 방향:

4분할 카드 구조. 각 카드에는 짧은 라벨과 아이콘을 배치한다.

## Slide 5. 직원이 사용하는 기본 흐름

핵심 문장:

`요청하고, 참고 자료를 고르고, 초안을 검토한 뒤 저장합니다.`

흐름:

1. 요청 입력
2. 업무 맥락 선택
3. AI 초안 생성
4. 편집, 저장, 공유

이미지 방향:

왼쪽에서 오른쪽으로 이어지는 4단계 업무 플로우.

## Slide 6. 예시: 주간 업무 보고서 만들기

핵심 문장:

`업무 일지와 To-do를 바탕으로 주간 보고서 초안을 만듭니다.`

포인트:

* 이번 주 업무
* 완료한 일
* 다음 주 계획
* 리스크

이미지 방향:

업무 기록 카드와 To-do 카드가 주간 보고서 문서로 변환되는 장면.

## Slide 7. 사내 지식 검색

핵심 문장:

`필요한 문서를 찾고, AI가 요약과 출처를 함께 보여줍니다.`

포인트:

* 문서 검색
* 요약
* 출처 확인

이미지 방향:

검색창, 결과 목록, AI 요약 카드가 함께 있는 업무용 검색 화면.

## Slide 8. 안전하게 쓰는 AI

핵심 문장:

`AI는 내가 접근할 수 있는 자료만 참고합니다.`

포인트:

* 권한 준수
* 출처 표시
* 사용자가 최종 검토

이미지 방향:

문서 위의 방패 아이콘과 접근 가능한 자료만 AI에 연결되는 시각화.

## Slide 9. 각 부서에 주는 효과

핵심 문장:

`반복 문서 작성은 줄이고, 기존 지식의 재사용은 늘립니다.`

포인트:

* 보고서 작성 시간 감소
* 문서 품질 표준화
* 검색과 공유 개선

이미지 방향:

기획, 영업, 마케팅, 운영, 인사 등 부서별 카드가 하나의 Notive 허브와 연결되는 이미지.

## Slide 10. 마무리

핵심 문장:

`Notive는 우리가 일한 기록을 다음 문서와 다음 의사결정에 다시 쓰게 합니다.`

CTA:

`기록하기 -> 찾기 -> 생성하기 -> 공유하기`

이미지 방향:

업무 기록이 문서와 지식 자산으로 쌓이는 밝은 대시보드형 마무리 화면.

# 4. 이미지 제작 공통 지침

* 16:9 프레젠테이션 슬라이드 이미지
* 기업 내부 소개용, 밝고 차분한 업무용 SaaS 스타일
* 초록/청록 포인트 컬러
* 카드, 문서, 검색창, 업무 기록, AI 초안, 권한 방패 아이콘 활용
* 텍스트는 짧고 크게 배치
* 과도한 장식과 복잡한 기술 다이어그램은 피함
* 실제 코드나 개발자용 용어는 배제
* 슬라이드 번호를 작게 표시
