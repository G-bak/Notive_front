# Notive Company Library Screen Implementation Plan v1.0

## 1. 목적

이 문서는 제공된 레퍼런스 이미지 `[Image #1]`를 기준으로 Notive의 `회사 자료실` 화면을 구현하기 전 세부 구현 방향을 정의한다.

구현 시 기존 앱의 공통 사이드바와 상단 헤더는 유지하고, 콘텐츠 영역만 회사 자료실 화면으로 구성한다. 화면은 문서/폴더 탐색, 자료 목록, 업로드 모달, 선택 자료 상세 패널을 동시에 제공하는 업무용 자료 관리 콘솔이다.

---

## 2. 레퍼런스 이미지 분석

### 2.1 화면 목적

`회사 자료실`은 조직 공용 자료를 팀/폴더 단위로 보관하고 검색, 필터링, 업로드, 권한 확인, 관련 문서 탐색을 수행하는 화면이다.

주요 사용 흐름:

- 왼쪽 폴더 트리에서 자료 위치 선택
- 태그로 빠른 분류 필터 적용
- 상단 KPI로 자료 현황 확인
- 탭으로 전체/최근 업로드/승인 필요/외부 공유/보관함 전환
- 검색 및 필터로 중앙 테이블 자료 탐색
- 자료 행 선택 시 오른쪽 상세 패널 확인
- 업로드 버튼으로 자료 업로드 모달 표시

### 2.2 전체 레이아웃

레퍼런스는 4개 영역으로 구성된다.

1. 기존 앱 쉘
   - 왼쪽 고정 사이드바
   - 상단 고정 헤더

2. 회사 자료실 본문
   - 제목/설명
   - KPI 카드 4개
   - 탭 + 검색/필터/액션
   - 왼쪽 폴더/태그 패널
   - 중앙 자료 테이블

3. 오른쪽 선택 자료 정보 패널
   - 선택 자료 메타 정보
   - 접근 권한
   - 연결된 문서
   - 최근 활동
   - AI 활용 현황

4. 업로드 모달
   - 중앙 테이블 위에 작은 플로팅 모달 형태
   - 드래그 업로드 영역
   - 저장 위치/접근 범위/외부 공유 옵션
   - 업로드/취소 버튼

## 6. 상세 UI 사양

### 6.1 페이지 헤더

텍스트:

```text
회사 자료실
회사 공용 자료를 안전하게 보관하고 팀별로 공유합니다.
```

레이아웃:

- 제목은 좌측 정렬
- KPI 카드와 간격은 18-22px 수준
- 상단 헤더와 별도 카드 형태는 사용하지 않는다

### 6.2 KPI 카드

스타일:

- 4열 그리드
- 높이 약 96px
- border `#dfe6ee`
- radius 8px
- 값은 큰 숫자, `font-weight: 700`
- 아이콘은 우측 원형 또는 단순 라인 아이콘

### 6.3 탭

기능:

- 클릭 시 active 스타일 변경
- 선택 탭에 따라 테이블 목록 필터링

스타일:

- 하단 underline 2px
- active color `#006853`
- button padding 기반 간격
- `font-weight: 600`

### 6.4 툴바

요소:

- 검색 input: `자료명 검색...`
- 유형 select: `전체 유형`
- 팀 select: `전체 팀`
- 필터 버튼
- 업로드 버튼
- 새 폴더 버튼
- 더보기 아이콘 버튼

검색 input은 실제 입력 가능한 controlled input으로 구현한다.

### 6.5 왼쪽 폴더 패널

구조:

- 상단 제목 `폴더`
- 폴더 트리
- 접기/펼치기 chevron
- 폴더 아이콘
- 오른쪽 count
- 선택 row pale green background

하단:

- `태그` 제목
- 우측 plus 버튼
- 태그 chip wrap

### 6.6 중앙 자료 테이블

테이블은 `<table>` 또는 CSS grid 중 하나를 선택한다.

권장:

- 실제 표 데이터이므로 `<table>` 사용을 우선 검토
- 기존 프로젝트 패턴이 grid table이면 grid 사용 가능

컬럼 폭:

```text
이름: 가장 넓게
유형: 고정폭
소유 팀: 고정폭
접근 범위: 중간폭
최종 업데이트: 중간폭
크기: 고정폭
승인 상태: 고정폭
```

긴 텍스트:

- 이름/접근 범위는 말줄임 가능
- 유형/크기/승인 상태는 말줄임 금지

행 스타일:

- 높이 46-52px
- hover background `#fbfdff`
- selected row `#eff8f4`
- 파일 유형별 작은 컬러 아이콘 사용

### 6.7 업로드 모달

표시:

- 중앙 테이블 오른쪽 하단 위에 floating modal
- 기본 상태로 표시할지, 업로드 버튼 클릭 시 표시할지는 구현 단계에서 결정
- 레퍼런스는 열려 있는 상태

구성:

- 제목 `자료 업로드`
- 닫기 x
- 드래그 앤 드롭 영역
- `파일 선택` 버튼
- 최대 용량 안내
- 저장 위치 breadcrumb input
- 접근 범위 select
- 외부 공유 checkbox
- 업로드 primary button
- 취소 secondary button

### 6.8 오른쪽 상세 패널

구조:

- 메인 콘텐츠와 분리된 오른쪽 컬럼
- `classification` 화면처럼 absolute 배치 금지
- 페이지 레이아웃 grid의 형제 컬럼으로 구성

권장 구조:

```jsx
<div className="company-library-layout">
  <main className="company-library-main">...</main>
  <aside className="company-library-inspector">...</aside>
</div>
```

섹션:

- 선택한 자료 정보
- 접근 권한
- 연결된 문서
- 최근 활동
- AI 활용 현황

오른쪽 패널은 전체 페이지 높이에 맞게 독립 스크롤 가능하게 처리한다.

- 카드/패널: 8px
- 버튼/input: 6-7px
- 배지/chip: 6px

## 10. 반응형 기준

기본 타겟은 데스크톱이다.

### 10.1 1600px 이상

- main + inspector 2컬럼
- 왼쪽 폴더 패널 + 중앙 테이블 2컬럼
- 업로드 모달은 테이블 위에 floating

### 10.2 1400px 이하

- inspector를 아래로 내리거나 main 하단 full width로 배치
- 테이블은 horizontal scroll 허용

### 10.3 1180px 이하

- main 내부 폴더 패널과 테이블을 1컬럼으로 전환
- KPI는 2열
- toolbar는 줄바꿈

## 11. 수용 기준

완료 조건:

- `/company-library`에서 화면이 렌더링된다.
- 기존 사이드바와 상단 헤더는 유지된다.
- 회사 자료실 메뉴가 active 상태를 가진다.
- 화면은 레퍼런스처럼 왼쪽 폴더, 중앙 테이블, 오른쪽 상세 패널, 업로드 모달을 포함한다.
- 탭/폴더/검색/행 선택이 실제 UI 상태를 변경한다.
- 업로드 모달 열기/닫기 동작이 가능하다.
- 테이블 컬럼 정렬이 깨지지 않는다.
- 긴 텍스트는 지정된 컬럼에서만 말줄임 처리된다.
- `npm run build`가 성공한다.
- Playwright 확인 시 콘솔 warning/error가 없다.
