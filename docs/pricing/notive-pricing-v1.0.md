# Notive 요금제 정책 문서 v1.0

본 문서는 Notive의 요금제 구조와 도입 절차를 정의한다.

---

## 1. 문서 목적

* Notive를 도입하는 조직에 적용되는 사용 조건과 권한 범위를 명시한다.
* 영업·고객 성공 담당자가 일관된 안내를 할 수 있도록 표준 자료를 제공한다.
* 플랜 변경, 한도 정책, 결제 절차에 관한 운영 기준을 정의한다.

---

## 2. 적용 대상

* 본 정책은 Notive 웹 SaaS 플랫폼에 가입하는 모든 조직 및 개인 사용자에게 적용된다.
* On-Premise 및 VPC 환경 도입 조직은 별도의 엔터프라이즈 계약에 따른다.

---

## 3. 플랜 구성

Notive는 세 가지 플랜으로 구성된다.

| 플랜 | 대상 | 가격 모델 | 가격 |
| --- | --- | --- | --- |
| Free | 개인 사용자 | 무료 | ₩0 |
| Team | 조직 도입 | 사용자당 월 정액 | ₩29,000 / 사용자 / 월 |
| Enterprise | 대규모·보안 환경 | 협의 | 별도 산정 |

---

### 3.1 Free

| 항목 | 내용 |
| --- | --- |
| 대상 | Notive를 직접 사용해보고 싶은 개인 사용자 |
| 요금 | 무료 |
| 신용카드 | 등록 불필요 |
| 지원 | 헬프센터 · 메일 답변 영업일 기준 5일 이내 |

**포함 기능**

* AI 사용량 — 적은 한도 (개인 평가 목적)
* 업무 다이어리, To-do, 일정 관리
* 중앙 문서 저장 (1GB)
* 기본 문서 템플릿 5종
* 문서 검색 (제목, 본문, 태그)

---

### 3.2 Team

| 항목 | 내용 |
| --- | --- |
| 대상 | 팀 전체가 함께 문서를 만들고 정리하는 조직 |
| 가격 | **사용자 1명당 ₩29,000 / 월** |
| 인원 산정 | 관리자·직원 모두 1명으로 계산. 인원이 늘면 그만큼 비례 증가 |
| 지원 | 헬프센터 + 도입 담당자 |

**가격 산정 예시**

| 인원 구성 | 월 청구 |
| --- | --- |
| 2명 | ₩58,000 |
| 5명 | ₩145,000 |
| 10명 | ₩290,000 |
| 20명 | ₩580,000 |

**Free 기능 + 추가 포함 기능**

* AI 사용량 — Free의 5배
* 회사·부서 단위 양식 등록·관리
* 팀 단위 공유 · 검토 · 승인 흐름
* 역할 기반 권한 (Viewer · Editor · Manager · Admin)
* 통합 검색 (제목·본문·태그·작성자·팀·날짜 필터)
* AI 답변 검색 (자연어 질문 + 요약 + 출처 표시)
* 업무 다이어리·To-do 기반 보고서 자동 작성
* 저장 용량 사용자당 50GB

**도입 시 함께 진행되는 작업**

* 회사 양식 1–3종 등록 지원
* 사내 운영 가이드 1회 제공
* 첫 30일 도입 점검 미팅 1회

---

### 3.3 Enterprise

| 항목 | 내용 |
| --- | --- |
| 대상 | 사내망·전용 보안 환경이 필요한 대규모 조직 |
| 가격 | 별도 협의 (사용 규모·보안 요건에 따라 산정) |
| 지원 | 전담 매니저 · 전용 SLA |

**Team 기능 + 추가 포함 기능**

* AI 사용량 — Team의 10배
* On-Premise 또는 VPC 단독 환경 구성
* SSO 및 도메인 통합 (SAML, OIDC)
* SCIM 기반 사용자 자동 동기화
* 외부 협업 도구 연동 (Slack, Microsoft Teams, Google Workspace)
* 전담 매니저 배정
* 분기별 보안 보고서
* 전용 SLA · 폐쇄망 환경 대응
* 저장 용량 무제한

---

## 4. AI 사용량 정책

### 4.1 사용량 기준

* AI 사용량은 AI 문서 생성과 AI 답변 검색을 합산한 월별 한도로 운영한다.
* 플랜별 상대 비교: **Free = 1× / Team = Free의 5× / Enterprise = Team의 10×**.
* 정확한 한도 수치는 베타 운영 데이터를 기반으로 별도 공시한다.

### 4.2 한도 도달 정책

* 한도 도달 24시간 전 사용자에게 알림이 발송된다.
* 한도 도달 시 신규 AI 요청은 차단된다. 기존 문서의 조회·편집은 영향을 받지 않는다.
* Team과 Enterprise는 자동 단계 상향이 발생하지 않는다. 명시적 합의가 필요하다.

### 4.3 사용량 이월

* 사용하지 않은 사용량은 다음 달로 이월되지 않는다.
* 사용 주기는 매월 1일 00:00 KST 기준으로 초기화된다.

---

## 5. 결제 및 청구

* Free는 결제 처리가 발생하지 않는다.
* Team은 월 단위 자동 결제로 운영된다. 연 결제 선택 시 2개월분 할인을 제공한다.
* Enterprise는 연 단위 청구를 기본으로 한다.
* 결제 수단: 신용카드, 세금계산서 발행 가능한 계좌이체.
* 청구서는 영문 및 한국어 표기를 모두 제공한다.

---

## 6. 권한과 사용 제한

* AI 사용량, 저장 용량, 사용자 수 한도를 초과한 경우 24시간 전 사전 알림이 발송된다.
* 한도 도달 시 신규 생성·저장은 일시 중단된다. 기존 문서의 조회와 편집은 영향을 받지 않는다.
* Team 및 Enterprise는 한도 초과 시 자동 단계 상향이 발생하지 않는다.

---

## 7. 보안과 데이터

* 모든 플랜에서 회사별 데이터 분리, 사용자 권한에 따른 문서 접근 제어는 기본 제공된다.
* 외부 공유, 다운로드 허용 여부는 조직 관리자가 설정한다.
* 고객 데이터는 명시적 동의 없이는 AI 학습에 사용되지 않는다.
* Enterprise 플랜은 추가로 폐쇄망·VPC·전용 키 암호화 옵션을 제공한다.

---

## 8. 플랜 변경

* 플랜 변경은 사용자 측 요청으로 언제든 가능하다.
* 상향(Upgrade)은 즉시 반영되고 일할 계산으로 청구된다.
* 하향(Downgrade)은 다음 결제 주기 시작일에 반영된다.
* 사용자(직원) 추가는 즉시 반영되며, 추가일 기준으로 일할 계산하여 청구된다.
* 사용자 제외는 다음 결제 주기에 반영된다. 제외된 사용자의 문서는 90일간 보관 후 정책에 따라 처리된다.

---

## 9. 도입 문의 및 영업 안내

* 도입 상담 신청은 랜딩 페이지의 `요금제` 섹션 또는 `시작 가이드` CTA를 통해 접수된다.
* 영업팀은 24시간 이내 1차 응답한다. (영업일 기준)
* Team 도입 표준 일정: 신청 → 1–2일 내 미팅 → 3–5일 내 워크스페이스 셋업 완료.
* Enterprise 도입 표준 일정: 신청 → 5일 내 1차 미팅 → 보안·기술 검토 2–4주 → 계약·구축.

---

* 변경 이력은 본 문서 하단에 기록한다.
