# 문서 편집기 속성 탭 가이드 v1.0

# Notive Document Editor Properties Tab Guide

---

# 1. 문서 목적

본 문서는 `/documents/{documentId}` 우측 인스펙터의 `속성` 탭을 정의한다.

속성 탭은 현재 문서의 공유 상태, 태그, 버전, AI 생성 정보, 참조 출처, 민감 정보 주의 사항을 한곳에서 확인하고 관리하는 영역이다.

---

# 2. 화면 위치

* 페이지: `/documents/{documentId}`
* 우측 인스펙터 첫 번째 탭
* 구현 컴포넌트: `PropertiesPanel`

---

# 3. 탭 목적

속성 탭의 목적은 다음이다.

* 문서가 누구에게 공유되어 있는지 확인한다.
* 문서 소유자와 공유 대상 팀/그룹을 확인한다.
* 문서 태그를 확인하고 추가한다.
* 최신 버전과 과거 버전 요약을 확인한다.
* AI 생성 문서인 경우 생성 정보와 참고 컨텍스트를 확인한다.
* 생성 또는 작성에 사용된 참조 출처를 확인한다.
* 공유 전 민감 정보 경고를 제공한다.

---

# 4. 현재 화면 구성

현재 구현은 다음 섹션으로 구성된다.

1. 공유
2. 태그
3. 버전 기록
4. AI 생성 정보
5. 참조 출처
6. 민감 정보 경고

---

# 5. 공유 섹션

## 5.1 목적

현재 문서의 공유 범위와 공유 대상 정보를 보여준다.

현재 표시:

* 공유 범위: ACME 주식회사 전체
* 설명: 링크가 있는 모든 구성원
* 소유자: 김민지
* 공유 중인 팀/그룹: 마케팅팀, 경영진
* 팀/그룹 추가 버튼

## 5.2 후속 구현 기준

공유 범위는 `documents.visibility`와 `document_shares`를 기준으로 표시한다.

공유 범위 예시:

* Private
* Team
* Organization
* SpecificUsers

공유 대상 유형:

* User
* Team
* Organization

접근 권한:

* View
* Edit
* Manage

## 5.3 권한 기준

공유 설정 변경은 Manage 권한이 필요하다.

권한이 없는 사용자는 공유 정보만 볼 수 있거나, 민감한 공유 대상은 제한적으로 표시한다.

---

# 6. 태그 섹션

## 6.1 목적

문서 검색, 분류, 필터링에 사용할 태그를 보여준다.

현재 태그:

* 마케팅
* 분기보고
* 성과분석

## 6.2 후속 구현 기준

태그는 `document_tags`와 `document_tag_links` 기준으로 연결한다.

태그 추가 시:

* 기존 태그 검색
* 새 태그 생성
* 중복 태그 방지
* 권한 확인

---

# 7. 버전 기록 섹션

## 7.1 목적

최근 문서 버전을 요약해 보여주고 전체 버전 목록으로 진입하게 한다.

현재 표시:

* v1.2 현재
* v1.1 편집
* v1.0 최초 작성
* 모든 버전 보기

## 7.2 후속 구현 기준

버전은 `document_versions` 기준으로 표시한다.

표시 항목:

* 버전 번호
* 변경 요약
* 변경자
* 생성 시각
* 현재 버전 여부

전체 버전 보기에서는 이전 본문 미리보기와 복원을 제공한다.

복원은 Manage 권한 또는 정책상 허용된 사용자에게만 제공한다.

---

# 8. AI 생성 정보 섹션

## 8.1 목적

문서가 AI 생성 또는 AI 보조 작업을 통해 만들어졌는지 확인한다.

현재 표시:

* 생성 일시
* 생성자: Notive AI
* 참고 컨텍스트 수
* 프롬프트 및 컨텍스트 보기

## 8.2 후속 구현 기준

AI 생성 정보는 다음 데이터와 연결된다.

* `documents.source_type`
* `documents.ai_request_id`
* `ai_requests`
* `ai_results`
* `ai_references`

단, AI 요청 원문과 AI 응답 본문은 보존 정책에 따라 장기 저장하지 않는다.

프롬프트 및 컨텍스트 보기에서는 민감 정보 노출을 제한해야 한다.

---

# 9. 참조 출처 섹션

## 9.1 목적

문서 생성 또는 보강에 사용된 참고 자료를 보여준다.

현재 표시:

* 2024년 2분기 마케팅 전략 회의록
* 1분기 마케팅 성과 보고서
* 마케팅 캠페인 성과 데이터 (Q2)

## 9.2 후속 구현 기준

참조 출처는 `ai_references` 또는 검색/문서 연결 데이터 기준으로 표시한다.

표시 항목:

* 출처 제목
* 출처 유형
* 수정일 또는 생성 시각
* 원문 열기
* 접근 제한 상태

출처 열기 시 권한을 다시 확인한다.

---

# 10. 민감 정보 경고

## 10.1 목적

문서에 매출, 광고비, 개인정보, 보안 정책 등 민감 정보가 포함될 가능성이 있을 때 공유 전 주의를 제공한다.

현재 문구:

```text
이 문서는 매출·광고비 등 민감 정보를 포함합니다. 외부 공유 전 민감 정보 검사를 권장합니다.
```

## 10.2 후속 구현 기준

민감 정보 점검은 AI 어시스턴트의 `민감 정보 점검`과 연결할 수 있다.

점검 결과는 다음처럼 표시한다.

* 매출/비용 수치 포함
* 개인정보 가능성
* 외부 공유 제한 문구 필요
* 보안 정책 검토 필요

---

# 11. 데이터/API 연결 기준

| 섹션 | 데이터/API |
| --- | --- |
| 공유 | `documents.visibility`, `document_shares`, `PUT /documents/{documentId}/shares` |
| 태그 | `document_tags`, `document_tag_links`, 문서 수정 API |
| 버전 | `document_versions`, `GET /documents/{documentId}/versions` |
| AI 생성 정보 | `documents.ai_request_id`, `ai_requests`, `ai_results` |
| 참조 출처 | `ai_references`, 검색 출처, 문서 연결 |
| 민감 정보 경고 | AI 점검 결과 또는 정책 기반 룰 |
