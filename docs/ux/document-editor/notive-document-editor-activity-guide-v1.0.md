# 문서 편집기 활동 탭 가이드 v1.0

# Notive Document Editor Activity Tab Guide

---

# 1. 문서 목적

본 문서는 `/documents/{documentId}` 우측 인스펙터의 `활동` 탭을 정의한다.

활동 탭은 현재 문서에서 발생한 주요 변경, AI 보조 작업, 공유 변경, 버전 이벤트를 시간순으로 보여주는 문서 단위 타임라인이다.

---

# 2. 화면 위치

* 페이지: `/documents/{documentId}`
* 우측 인스펙터 세 번째 탭
* 구현 컴포넌트: `ActivityPanel`

---

# 3. 탭 목적

활동 탭의 목적은 다음이다.

* 현재 문서에서 누가 무엇을 했는지 확인한다.
* 문서 수정, 공유 변경, 버전 생성, AI 결과 삽입 같은 주요 이벤트를 추적한다.
* 문서가 어떤 흐름으로 만들어지고 변경되었는지 빠르게 파악한다.
* 문제 발생 시 최근 변경 원인을 찾는다.
* 민감한 본문 원문 없이 감사성 메타데이터를 제공한다.

---

# 4. 관리자 활동 로그와의 차이

관리자 활동 로그는 조직 전체 운영과 감사 목적의 화면이다.

문서 편집기 활동 탭은 현재 문서 하나에 대한 사용자 친화적 타임라인이다.

| 구분 | 문서 활동 탭 | 관리자 활동 로그 |
| --- | --- | --- |
| 범위 | 현재 문서 | 조직 전체 |
| 대상 사용자 | 문서 접근 권한이 있는 사용자 | Admin 또는 제한된 Manager |
| 목적 | 문서 변경 흐름 확인 | 감사, 운영, 보안 추적 |
| 표시 방식 | 타임라인 | 로그 목록/필터 |
| 민감 정보 | 본문 원문 미표시 | 본문 원문 미표시 |

---

# 5. 현재 화면 구성

현재 구현은 다음으로 구성된다.

1. 활동 필터
2. 활동 타임라인
3. 로그 민감 정보 안내

---

# 6. 활동 필터

## 6.1 목적

사용자가 타임라인에서 보고 싶은 이벤트 유형을 빠르게 좁힌다.

현재 필터:

* 전체
* 편집
* 공유
* AI
* 버전

## 6.2 후속 구현 기준

필터는 활동 이벤트의 `category` 또는 `action` 기준으로 동작한다.

권장 매핑:

| 필터 | 포함 이벤트 |
| --- | --- |
| 전체 | 모든 문서 활동 |
| 편집 | 문서 생성, 문서 수정, 태그 변경, 소유 팀 변경 |
| 공유 | 공유 범위 변경, 공유 대상 추가/삭제 |
| AI | AI 요청, AI 결과 삽입, AI 보강, 민감 정보 점검 |
| 버전 | 버전 생성, 버전 복원 |

---

# 7. 활동 타임라인

## 7.1 목적

현재 문서에서 발생한 이벤트를 최신순으로 보여준다.

현재 이벤트 예시:

* AI 결과 삽입
* 문서 수정
* 버전 생성
* 공유 범위 변경
* 태그 변경
* 소유 팀 변경
* 버전 복원
* 문서 생성

## 7.2 표시 항목

각 활동 항목은 다음 정보를 가진다.

* 아이콘
* 활동 유형
* 짧은 설명
* 수행자
* 수행자 아바타
* 발생 시각
* 상태 배지
* 보조 액션

현재 보조 액션 예시:

* 이 버전 보기
* 복원 내역 보기

---

# 8. 이벤트 정의

## 8.1 문서 이벤트

| 이벤트 | 설명 | 표시 예시 |
| --- | --- | --- |
| 문서 생성 | 문서가 처음 생성됨 | AI 문서 생성 화면에서 시작 |
| 문서 수정 | 본문 또는 제목이 수정됨 | 본문 3개 섹션 수정 |
| 태그 변경 | 태그가 추가/삭제됨 | `#성과분석` 추가 |
| 소유 팀 변경 | 문서 소유 팀이 변경됨 | 기획팀 -> 마케팅팀 |
| 문서 보관/삭제 | 문서 상태가 변경됨 | 문서 보관 처리 |

## 8.2 공유 이벤트

| 이벤트 | 설명 | 표시 예시 |
| --- | --- | --- |
| 공유 범위 변경 | visibility가 변경됨 | 마케팅팀 전용 -> ACME 주식회사 전체 |
| 공유 대상 추가 | 사용자/팀이 추가됨 | 경영진 그룹 View 권한 추가 |
| 공유 권한 변경 | View/Edit/Manage 권한 변경 | 마케팅팀 View -> Edit |
| 공유 대상 제거 | 공유 대상 삭제 | 외부 협력자 제거 |

외부 공유 링크는 MVP 범위에서 제외되어 있으므로 표시하지 않는다.

## 8.3 AI 이벤트

| 이벤트 | 설명 | 표시 예시 |
| --- | --- | --- |
| AI 요청 실행 | AI 어시스턴트에서 요청 실행 | 참고 자료 보강 요청 |
| AI 요청 실패 | AI 처리 실패 | 참고 자료 권한 오류 |
| AI 결과 삽입 | AI 결과를 본문에 삽입 | `3. 주요 캠페인 성과` 섹션에 보강 결과 삽입 |
| 선택 영역 교체 | AI 결과로 선택 영역 대체 | 요약 문단 교체 |
| 민감 정보 점검 | 민감 정보 검사 실행 | 매출/광고비 포함 항목 확인 |

AI 요청 원문과 응답 본문 전체는 활동 로그에 저장하지 않는다.

## 8.4 버전 이벤트

| 이벤트 | 설명 | 표시 예시 |
| --- | --- | --- |
| 버전 생성 | 명시 저장 또는 정책상 버전 생성 | v1.2 자동 저장 |
| 버전 복원 | 과거 버전으로 복원 | v1.1 본문 일부를 v1.0 기준으로 복원 |
| AI 결과 저장 | AI 결과가 문서로 저장됨 | AI 결과 저장 후 v1.0 생성 |

# 9. 로그 민감 정보 원칙

활동 탭 하단에는 다음 안내를 표시한다.

```text
본문 변경 원문, AI 요청 내용, 검색어 원문은 활동 로그에 기록되지 않습니다.
```

이 원칙은 다음 보안 기준을 따른다.

* 본문 원문을 로그에 저장하지 않는다.
* AI 요청 원문을 로그에 저장하지 않는다.
* AI 응답 본문 전체를 로그에 저장하지 않는다.
* 검색어 원문을 문서 활동 로그에 저장하지 않는다.
* 필요한 경우 메타데이터만 저장한다.

# 10. 데이터/API 연결 기준

## 10.1 현재 필요한 데이터

활동 항목은 다음 필드를 가진다.

```json
{
  "id": "activity_id",
  "organizationId": "organization_id",
  "documentId": "document_id",
  "actorUserId": "user_id",
  "actorName": "김민지",
  "action": "document.updated",
  "category": "edit",
  "targetType": "Document",
  "targetId": "document_id",
  "result": "Success",
  "summary": "본문 3개 섹션 수정",
  "metadata": {
    "versionNumber": "v1.2"
  },
  "createdAt": "2026-05-11T12:00:00Z"
}
```

## 10.2 API 필요 사항

현재 API 명세에는 관리자 활동 로그 조회가 있다.

```http
GET /organizations/{organizationId}/admin/activity-logs
```

문서 활동 탭을 실제 데이터로 연결하려면 문서 범위 조회가 필요하다.

권장 API:

```http
GET /organizations/{organizationId}/documents/{documentId}/activities
```

Query:

| 파라미터 | 설명 |
| --- | --- |
| category | All, Edit, Share, AI, Version |
| page | 페이지 |
| pageSize | 페이지 크기 |

권한:

* 문서 View 권한 보유 사용자
* 민감한 관리자 전용 이벤트는 표시 제한 가능

---

# 11. 권한 기준

활동 탭 조회는 문서 View 권한을 기준으로 한다.

단, 모든 이벤트를 모든 사용자에게 보여줄 필요는 없다.

| 이벤트 | 기본 표시 대상 |
| --- | --- |
| 문서 생성/수정 | 문서 View 권한 사용자 |
| 공유 범위 변경 | 문서 View 권한 사용자, 상세는 Manage 권한 우선 |
| 버전 생성 | 문서 View 권한 사용자 |
| 버전 복원 | 문서 View 권한 사용자, 복원 액션은 Manage 권한 |
| AI 결과 삽입 | 문서 View 권한 사용자 |
| AI 요청 실패 상세 | 요청 사용자 또는 Admin 정책 |

---

# 12. 상태 및 빈 화면

## 12.1 활동 없음

문서 생성 직후 활동이 적을 수 있다.

표시 기준:

* 빈 상태 문구
* 문서 생성 이벤트가 있다면 최소 1개 표시

## 12.2 필터 결과 없음

선택한 필터에 해당하는 활동이 없으면 다음을 표시한다.

* `해당 유형의 활동이 없습니다`
* 필터 초기화 버튼

## 12.3 로그 로딩 실패

표시 기준:

* 재시도 버튼
* 본문 편집은 계속 가능해야 함
