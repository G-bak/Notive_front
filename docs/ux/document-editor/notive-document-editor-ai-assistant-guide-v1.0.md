# 문서 편집기 AI 어시스턴트 탭 가이드 v1.0

# Notive Document Editor AI Assistant Tab Guide

---

# 1. 문서 목적

본 문서는 Notive 문서 편집 화면(`/documents/{documentId}`) 우측 인스펙터에 배치된 **AI 어시스턴트** 탭의 목적, 사용 위치, 화면 구성, 동작 원칙, 권한 기준, 후속 구현 기준을 정의한다.

이 문서는 전체 AI 문서 생성 화면의 설계서가 아니다. 이미 열린 문서를 기준으로 사용자가 문서를 다듬고, 보강하고, 검토하고, 편집기에 반영하도록 돕는 **문서 내 보조 패널**의 기준 문서다.

---

# 2. 화면 위치

## 2.1 진입 경로

* 경로: `/documents/{documentId}`
* 현재 구현 파일: `src/pages/DocumentEditor.jsx`
* 우측 패널 탭: `속성`, `AI 어시스턴트`, `활동`

## 2.2 화면 내 역할

AI 어시스턴트는 문서 편집기 오른쪽에 고정된 보조 패널이다.

사용자는 왼쪽에서 문서를 읽거나 편집하면서, 오른쪽 AI 어시스턴트에서 다음 작업을 수행한다.

* 현재 문서 요약
* 문체 다듬기
* 이어쓰기
* 표로 정리
* 확인 필요 항목 탐지
* 액션 아이템 추출
* 참고 자료 기반 내용 보강
* 민감 정보 점검
* AI 결과를 문서 본문에 삽입 또는 선택 영역 교체

---

# 3. 제품 내 구분

## 3.1 AI 문서 생성 화면과의 차이

`AI 문서 생성` 화면은 새 문서 초안을 만들기 위한 시작 화면이다.

AI 어시스턴트 탭은 이미 열려 있는 문서를 기준으로 작동한다.

| 구분 | AI 문서 생성 화면 | 문서 편집기 AI 어시스턴트 |
| --- | --- | --- |
| 목적 | 새 문서 초안 생성 | 현재 문서 개선과 검토 |
| 진입 위치 | 사이드 메뉴 `AI 문서 생성` | `/documents/{documentId}` 우측 패널 |
| 기본 컨텍스트 | 사용자가 선택한 문서 유형, 템플릿, 참고 자료 | 현재 문서, 연결된 참조 출처, 업무 기록, To-do |
| 결과 처리 | 새 Draft/Active 문서로 저장 | 현재 문서에 삽입, 선택 영역 교체, 복사 |
| 위험 | 새 문서 품질과 저장 흐름 | 기존 문서 훼손, 근거 없는 덮어쓰기 |

## 3.2 속성 탭과의 차이

`속성` 탭은 문서의 메타데이터와 관리 정보를 보여준다.

AI 어시스턴트는 문서 내용을 바탕으로 사용자가 바로 활용할 수 있는 초안, 개선안, 점검 결과를 생성한다.

## 3.3 활동 탭과의 차이

`활동` 탭은 문서의 변경 이력과 감사성 로그를 보여준다.

AI 어시스턴트는 사용자가 현재 시점에 실행할 작업을 제공한다. AI 결과 삽입, 선택 영역 교체, 재생성 등은 수행 후 활동 탭에 이벤트로 남을 수 있다.

# 4. 핵심 원칙

## 4.1 AI 결과는 초안

AI 어시스턴트의 모든 결과는 최종 문서가 아니라 초안이다.

사용자가 검토하고 명시적으로 삽입, 교체, 저장해야 문서에 반영된다.

## 4.2 현재 문서 중심

기본 컨텍스트는 현재 열린 문서다.

선택된 참고 자료가 있더라도 AI 어시스턴트는 현재 문서의 목적, 유형, 기존 본문 흐름을 우선 고려해야 한다.

## 4.3 출처 기반

참고 자료를 사용한 결과에는 출처를 표시해야 한다.

출처가 없거나 권한상 표시할 수 없는 경우, 근거 기반 답변처럼 보이게 만들면 안 된다.

## 4.4 권한 준수

AI가 사용할 수 있는 자료는 사용자가 접근 가능한 자료로 제한한다.

권한 없는 문서, 다른 조직 문서, 삭제된 문서, 접근할 수 없는 업무 기록, 접근할 수 없는 To-do는 참고 자료로 포함하지 않는다.

## 4.5 비파괴 동작

AI 결과는 기존 문서를 자동으로 덮어쓰지 않는다.

`삽입`, `선택 영역 교체`, `복사`, `재생성`, `요청 수정`처럼 사용자가 의도를 선택한 뒤에만 반영한다.

# 5. 현재 화면 구성

현재 구현된 AI 어시스턴트 탭은 다음 섹션으로 구성된다.

## 5.1 컨텍스트 요약 카드

화면 상단의 카드다.

표시 내용:

* 안내 문구: `이 문서를 바탕으로 도와드려요`
* 현재 AI가 참고하는 범위 요약
* 문서 유형
* 컨텍스트 수
* 권한 안내: `접근 가능한 자료만 AI가 사용합니다`

역할:

* 사용자가 AI가 무엇을 근거로 동작하는지 빠르게 이해하게 한다.
* AI가 모든 조직 데이터를 임의로 읽는 것이 아니라, 현재 권한 내 자료만 사용한다는 신뢰 기준을 제공한다.

## 5.2 빠른 작업

자주 쓰는 문서 편집 보조 작업을 버튼으로 제공한다.

현재 버튼:

* 요약하기
* 문체 다듬기
* 이어쓰기
* 표로 정리
* 확인 필요 항목
* 액션 아이템 추출
* 참고 자료 보강
* 민감 정보 점검

각 버튼은 프롬프트 입력 없이도 실행 가능한 작업이다.

후속 구현에서는 버튼 클릭 시 내부적으로 고정된 작업 타입과 현재 문서 컨텍스트를 조합하여 AI 요청을 만든다.

## 5.3 요청 입력

사용자가 직접 자연어로 요청을 입력하는 영역이다.

표시 요소:

* textarea
* 현재 문서 컨텍스트 사용 안내
* 보내기 버튼
* 예시 요청 칩

현재 예시 칩:

* 임원 보고용으로 줄여줘
* 다음 분기 실행 계획을 추가해줘
* 근거 없는 수치를 표시해줘

역할:

* 빠른 작업에 없는 구체적인 요구를 입력한다.
* 사용자가 문서 목적, 대상 독자, 원하는 톤을 직접 지정할 수 있게 한다.

## 5.4 참고 자료

AI 요청에 포함할 수 있는 자료 목록이다.

현재 표시 대상:

* 현재 문서
* 참조 문서
* 업무 다이어리
* To-do

각 항목은 다음 정보를 가진다.

* 자료 유형
* 제목
* 날짜 또는 상태
* 선택 여부
* 원문 열기 진입

후속 구현에서는 체크 상태가 실제 AI 요청의 `references`에 반영되어야 한다.

## 5.5 최근 결과

가장 최근 AI 응답을 카드 형태로 보여준다.

표시 요소:

* 생성 결과 본문
* 확인 필요 항목
* 출처 목록
* 삽입
* 선택 영역 교체
* 복사
* 재생성
* 요청 수정
* 초안 안내 문구

역할:

* AI 응답을 문서 본문에 반영하기 전 검토하는 공간이다.
* 출처와 확인 필요 항목을 함께 보여 신뢰도를 판단하게 한다.

# 6. 주요 사용 시나리오

## 6.1 현재 문서 요약

1. 사용자가 `AI 어시스턴트` 탭을 연다.
2. `요약하기`를 선택한다.
3. AI는 현재 문서와 선택된 참고 자료를 기준으로 요약 초안을 생성한다.
4. 결과 카드에 요약과 출처가 표시된다.
5. 사용자는 복사하거나 문서 상단에 삽입한다.

## 6.2 문체 다듬기

1. 사용자가 본문 일부를 선택한다.
2. `문체 다듬기`를 선택한다.
3. AI는 선택 영역을 업무 문서 톤으로 정리한다.
4. 사용자는 `선택 영역 교체`를 눌러 반영한다.

선택 영역이 없을 경우:

* 현재 섹션 또는 전체 문서를 대상으로 할지 선택하도록 안내한다.

## 6.3 참고 자료 기반 보강

1. 사용자가 참고 자료 목록에서 사용할 문서를 선택한다.
2. `참고 자료 보강`을 선택한다.
3. AI는 현재 문서의 부족한 부분을 선택된 출처 기준으로 보강한다.
4. 결과에 사용된 출처와 확인 필요 항목을 표시한다.
5. 사용자는 `삽입` 또는 `선택 영역 교체`로 반영한다.

## 6.4 확인 필요 항목 찾기

1. 사용자가 `확인 필요 항목`을 선택한다.
2. AI는 본문과 출처 간 불일치, 근거 없는 수치, 모호한 표현을 찾는다.
3. 결과 카드에 확인 필요 항목을 별도 표시한다.

예시:

* 동일 지표의 수치가 출처마다 다름
* 본문에 있는 일정이 참고 자료에 없음
* 민감 정보 가능성이 있는 매출/광고비 수치 포함

## 6.5 액션 아이템 추출

1. 사용자가 회의록, 보고서, 캠페인 문서에서 `액션 아이템 추출`을 선택한다.
2. AI는 담당자, 마감일, 상태가 드러나는 문장을 추출한다.
3. 결과는 문서에 삽입하거나 To-do 생성 흐름으로 연결할 수 있다.

MVP에서는 To-do 자동 생성보다 초안 목록 제공을 우선한다.

# 8. 데이터 및 API 연결 기준

## 8.1 현재 문서

문서 본문과 메타데이터는 문서 상세 API 기준이다.

```http
GET /organizations/{organizationId}/documents/{documentId}
```

사용 목적:

* 현재 문서 제목
* 본문
* 문서 유형
* 태그
* 소유 팀
* 공유 범위
* AI 생성 여부

## 8.2 AI 요청

AI 어시스턴트의 요청은 기존 AI 문서 생성 API와 같은 원칙을 공유하되, 요청 목적이 `current-document-assist` 또는 유사한 작업 유형으로 구분되어야 한다.

기준 API:

```http
POST /organizations/{organizationId}/ai/generate-document
```

후속 구현 시 권장 요청 구성:

```json
{
  "documentId": "document_id",
  "mode": "assist_current_document",
  "actionType": "summarize | improve_tone | continue | table | check_uncertain | extract_actions | enrich_with_sources | sensitive_check",
  "requestText": "임원 보고용으로 줄여줘",
  "selectedRange": {
    "start": 120,
    "end": 460
  },
  "references": [
    {
      "targetType": "Document",
      "targetId": "document_id"
    }
  ]
}
```

현재 API 명세에 `mode`, `actionType`, `selectedRange`가 없으므로 실제 구현 전 API 확장이 필요하다.

## 8.3 참고 자료

참고 자료는 `AIReference`로 연결한다.

대상 유형:

* Document
* Template
* DiaryEntry
* Todo

선택 가능한 자료는 반드시 사용자의 접근 권한으로 필터링한다.

## 8.4 결과 반영

AI 결과를 현재 문서에 반영하는 액션은 문서 수정 API를 사용한다.

```http
PATCH /organizations/{organizationId}/documents/{documentId}
```

반영 방식:

* 삽입
* 선택 영역 교체
* 복사만 수행
* 재생성
* 요청 수정

문서 변경이 발생하면 버전 생성 정책과 활동 로그 정책을 따른다.

# 9. 권한 및 보안 기준

## 9.1 접근 권한

AI 어시스턴트는 Editor 이상 사용자에게 제공하는 것을 기본으로 한다.

Viewer는 AI 생성 권한이 없으므로 다음 중 하나로 처리한다.

* 탭 숨김
* 탭 표시 후 접근 제한 안내

현재 제품 원칙상 사용자가 할 수 없는 작업은 숨기거나 비활성화한다.

## 9.2 참고 자료 권한

AI 요청 시 다음을 확인한다.

1. 요청 사용자가 Editor 이상인가
2. 현재 문서에 View 이상 권한이 있는가
3. 현재 문서를 수정하려면 Edit 이상 권한이 있는가
4. 선택된 모든 참고 자료에 View 권한이 있는가
5. 모든 자료가 같은 조직에 속하는가
6. 삭제 또는 비활성 자료가 아닌가

## 9.3 출처 접근

결과 카드의 출처를 열 때도 권한을 다시 확인한다.

생성 당시에는 접근 가능했지만 이후 권한이 사라진 출처는 접근 제한 상태로 표시한다.

## 9.4 민감 정보 제한

AI 요청 원문, 검색어 원문, 문서 본문 전체는 활동 로그에 저장하지 않는다.

로그에는 작업 유형, 대상, 결과, 시각, 수행자 같은 메타데이터 중심으로 기록한다.

# 10. 결과 카드 동작 기준

## 10.1 삽입

AI 결과를 현재 커서 위치 또는 현재 섹션 하단에 추가한다.

선택 영역이 있더라도 자동으로 덮어쓰지 않는다.

## 10.2 선택 영역 교체

사용자가 선택한 본문 범위가 있을 때만 활성화한다.

선택 영역이 없으면 비활성화하거나 선택 안내를 표시한다.

## 10.3 복사

AI 결과 본문만 클립보드에 복사한다.

출처와 확인 필요 항목은 별도 옵션으로 포함할 수 있다.

## 10.4 재생성

기존 문서를 자동으로 변경하지 않는다.

재생성 결과는 새 후보로 유지하고 사용자가 선택한 결과만 반영한다.

## 10.5 요청 수정

직전 요청과 선택된 참고 자료를 유지한 상태에서 프롬프트 입력으로 되돌아간다.

# 11. 활동 로그 연결

AI 어시스턴트에서 다음 행동이 발생하면 활동 탭 또는 관리자 활동 로그에 기록할 수 있다.

| 사용자 행동 | 활동 유형 | 로그 수준 |
| --- | --- | --- |
| AI 요청 실행 | AI 생성 요청 | 메타데이터 |
| AI 요청 실패 | AI 생성 실패 | 메타데이터 |
| AI 결과 삽입 | AI 결과 삽입 | 문서 활동 |
| 선택 영역 교체 | AI 결과로 본문 교체 | 문서 활동 |
| 민감 정보 점검 | 민감 정보 점검 실행 | 필요 시 메타데이터 |
| AI 결과 저장 | AI 결과 저장 | 감사 로그 |

로그에 저장하지 않는 항목:

* AI 요청 원문 전체
* AI 응답 본문 전체
* 문서 본문 변경 원문
* 검색어 원문

---

# 12. 빈 상태와 오류 상태

## 12.1 참고 자료 없음

표시 기준:

* 현재 문서만 컨텍스트로 사용 가능하다고 안내
* 참고 자료 추가 또는 검색에서 가져오기 액션 제공

## 12.2 권한 없는 참고 자료

표시 기준:

* 목록에 표시하지 않는 것을 우선한다.
* 생성 이후 권한이 사라진 출처는 `접근 제한됨` 상태로 표시한다.

## 12.3 AI 생성 실패

표시 기준:

* 실패 사유를 사용자 행동 기준으로 안내한다.
* 재시도와 요청 수정 액션을 제공한다.
* 작성 중인 요청 내용은 유지한다.

## 12.4 출처 부족

표시 기준:

* 단정형 결과 대신 확인 필요 항목을 표시한다.
* 출처 없이 확정된 사실처럼 보이는 답변을 제공하지 않는다.

# 14. 후속 구현 체크리스트

## 14.1 기능

* 빠른 작업 버튼별 `actionType` 정의
* 요청 입력값 상태 관리
* 참고 자료 선택 상태 관리
* 현재 문서 선택 영역 연동
* AI 요청 API 연결
* 생성 진행 상태 표시
* 실패 상태와 재시도 처리
* 결과 후보 여러 개 관리
* 삽입/선택 영역 교체 실제 문서 반영
* 반영 후 자동 저장 또는 명시 저장 정책 연결

## 14.2 권한

* Viewer 접근 제한
* 현재 문서 View/Edit 권한 분리
* 참고 자료 View 권한 검사
* 출처 열기 시 권한 재검사
* 삭제/보관 문서 참고 제외
* 다른 조직 자료 참고 차단

## 14.3 데이터

* AIRequest 메타데이터 저장
* AIResult 메타데이터 저장
* AIReference 저장
* AIUsage 기록
* 문서 수정 시 DocumentVersion 생성
* AI 결과 삽입 시 ActivityLog 기록

## 14.4 UX

* 선택 영역이 없을 때 교체 버튼 비활성화
* 결과 반영 전 미리보기 유지
* 긴 결과 스크롤 처리
* 출처가 많은 경우 접기/더보기
* 모바일 또는 좁은 화면에서 우측 패널 대체 진입 방식 검토

# 15. QA 기준

AI 어시스턴트는 다음 기준으로 검증한다.

| 케이스 | 기대 결과 |
| --- | --- |
| Editor가 AI 어시스턴트 사용 | 요청 가능 |
| Viewer가 AI 어시스턴트 사용 | 차단 또는 비활성화 |
| 권한 없는 문서 참고 | 참고 자료 목록 미노출 또는 요청 차단 |
| 다른 조직 문서 참고 | 요청 차단 |
| 삭제된 문서 참고 | 참고 자료에서 제외 |
| 출처 기반 결과 | 출처 목록 표시 |
| 출처 부족 결과 | 확인 필요 표시 |
| 재생성 | 기존 문서 자동 변경 없음 |
| 삽입 | 사용자가 선택한 후에만 문서 반영 |
| 선택 영역 교체 | 선택 영역이 있을 때만 수행 |
| AI 요청 실패 | 입력 유지, 재시도 제공 |
| 활동 로그 | 본문 원문 없이 메타데이터 기록 |

# 17. 결정 사항

* AI 어시스턴트는 새 문서 생성 화면이 아니라 현재 문서 보조 패널이다.
* 결과는 항상 초안으로 취급한다.
* 사용자의 명시 액션 없이 현재 문서를 변경하지 않는다.
* 참고 자료와 출처는 권한 있는 항목만 사용한다.
* 활동 로그에는 본문과 AI 원문을 저장하지 않고 메타데이터 중심으로 기록한다.
