# 문서 편집 페이지 전체 가이드 v1.0

# Notive Document Editor Page Guide

---

# 1. 문서 목적

본 문서는 Notive의 문서 편집 페이지(`/documents/{documentId}`) 전체 화면 구조와 각 영역의 책임을 정의한다.

이 페이지는 사용자가 문서를 읽고, 편집하고, 공유 설정을 확인하고, AI 도움을 받아 본문을 보강하고, 변경 이력을 확인하는 중심 화면이다.

---

# 2. 화면 위치

* 라우트: `/documents/{documentId}`
* 현재 예시 라우트: `/documents/1`
* 구현 파일: `src/pages/DocumentEditor.jsx`
* 스타일 파일: `src/pages/DocumentEditor.css`

---

# 3. 페이지 구조

문서 편집 페이지는 크게 두 영역으로 나뉜다.

| 영역 | 설명 |
| --- | --- |
| 좌측 문서 편집 영역 | 문서 경로, 제목, 메타 칩, 편집 툴바, 본문 캔버스, 상태바 |
| 우측 인스펙터 | 속성, AI 어시스턴트, 활동 탭 |

현재 레이아웃은 데스크톱에서 좌측 편집 영역과 우측 360px 인스펙터를 나란히 배치한다.

1024px 이하에서는 우측 인스펙터를 숨기는 방식으로 반응형 처리한다.

---

# 4. 페이지 목적

문서 편집 페이지의 목적은 다음이다.

* 사용자가 문서를 열람한다.
* 사용자가 제목, 본문, 태그, 문서 유형 등 문서 정보를 수정한다.
* 문서 저장 상태와 기본 통계를 확인한다.
* 공유 범위, 소유자, 버전, 출처 등 문서 메타데이터를 확인한다.
* AI 어시스턴트를 통해 현재 문서를 보강하거나 점검한다.
* 문서 변경 이력과 주요 활동을 확인한다.

---

# 5. 주요 사용자 흐름

## 5.1 문서 열람

1. 사용자가 문서 목록, 최근 문서, 검색 결과 등에서 문서를 연다.
2. 시스템은 문서 접근 권한을 확인한다.
3. 문서 제목, 본문, 메타데이터, 우측 속성 정보를 표시한다.

## 5.2 문서 편집

1. 사용자가 문서 본문 또는 제목을 수정한다.
2. 시스템은 임시 저장 또는 자동 저장 상태를 표시한다.
3. 사용자가 명시 저장하거나 자동 저장 정책에 따라 저장한다.
4. 저장 시 필요하면 버전 기록을 생성한다.

## 5.3 문서 관리

1. 사용자가 우측 `속성` 탭에서 공유 범위, 태그, 버전, 참조 출처를 확인한다.
2. 공유 설정, 태그 추가, 버전 보기 같은 관리 액션을 수행한다.
3. 권한이 부족한 액션은 숨기거나 비활성화한다.

## 5.4 AI 보조 편집

1. 사용자가 `AI 어시스턴트` 탭을 연다.
2. 현재 문서와 선택된 참고 자료를 기준으로 빠른 작업 또는 직접 요청을 실행한다.
3. 결과를 검토한 뒤 삽입, 선택 영역 교체, 복사, 재생성을 선택한다.

## 5.5 활동 확인

1. 사용자가 `활동` 탭을 연다.
2. 문서 생성, 수정, 공유 변경, AI 결과 삽입, 버전 생성 같은 이벤트를 시간순으로 확인한다.
3. 필요한 경우 특정 버전 또는 복원 내역을 연다.

---

# 6. 우측 인스펙터 탭 역할

| 탭 | 목적 | 주요 내용 |
| --- | --- | --- |
| 속성 | 문서 메타데이터와 관리 정보 확인 | 공유, 태그, 버전, AI 생성 정보, 참조 출처, 민감 정보 경고 |
| AI 어시스턴트 | 현재 문서 기준 AI 보조 작업 | 빠른 작업, 요청 입력, 참고 자료, 최근 결과 |
| 활동 | 현재 문서의 변경 이력과 감사성 활동 확인 | 필터, 활동 타임라인, 로그 민감 정보 안내 |

# 7. 데이터/API 연결 기준

## 7.1 문서 상세

```http
GET /organizations/{organizationId}/documents/{documentId}
```

사용 영역:

* 제목
* 본문
* 문서 유형
* 작성자/소유자
* 소유 팀
* 공유 범위
* 태그
* 생성일/수정일
* 버전 정보

## 7.2 문서 수정

```http
PATCH /organizations/{organizationId}/documents/{documentId}
```

사용 영역:

* 제목 수정
* 본문 수정
* 문서 유형 변경
* 태그 변경
* AI 결과 삽입 또는 선택 영역 교체

## 7.3 공유 설정

```http
PUT /organizations/{organizationId}/documents/{documentId}/shares
```

사용 영역:

* 공유 범위 변경
* 특정 팀/사용자 권한 부여

## 7.4 버전 목록

```http
GET /organizations/{organizationId}/documents/{documentId}/versions
```

사용 영역:

* 속성 탭 버전 요약
* 활동 탭 버전 이벤트

## 7.5 AI 요청

```http
POST /organizations/{organizationId}/ai/generate-document
```

문서 편집기 AI 어시스턴트에서는 현재 문서 보조 모드 확장이 필요하다.

## 7.6 활동 로그

현재 API 명세에는 관리자용 활동 로그가 중심이다.

```http
GET /organizations/{organizationId}/admin/activity-logs
```

문서 단위 활동 탭을 실제 데이터로 연결하려면 다음 중 하나가 필요하다.

* 문서별 활동 로그 API 추가
* 관리자 활동 로그 API에 `targetType=Document`, `targetId={documentId}` 필터 추가

---

# 8. 권한 원칙

* 문서 조회는 View 권한이 필요하다.
* 본문 수정은 Edit 권한이 필요하다.
* 공유 설정, 삭제, 복원은 Manage 권한이 필요하다.
* AI 어시스턴트 실행은 Editor 이상이어야 한다.
* 참고 자료는 사용자가 접근 가능한 자료만 AI 요청에 포함한다.
* 직접 URL 접근 시에도 서버가 문서 권한을 다시 확인한다.

---

# 9. 보안 및 로그 원칙

* 권한 없는 문서의 존재를 화면에서 암시하지 않는다.
* AI 요청 원문과 AI 응답 본문 전체를 장기 저장하지 않는다.
* 활동 로그에는 문서 본문 원문, 검색어 원문, AI 요청 원문을 남기지 않는다.
* 문서 공유 범위 변경과 권한 변경은 우선순위 높은 활동 로그로 취급한다.
* 출처 문서 열기 시 권한을 다시 확인한다.
