# 문서 편집 영역 가이드 v1.0

# Notive Document Editor Canvas Guide

---

# 1. 문서 목적

본 문서는 `/documents/{documentId}` 페이지의 좌측 문서 편집 영역을 정의한다.

문서 편집 영역은 사용자가 실제 문서를 읽고 수정하는 주 작업 공간이다. 우측 인스펙터가 보조 정보와 도구를 제공한다면, 좌측 편집 영역은 문서 자체를 다루는 핵심 표면이다.

---

# 2. 화면 구성

현재 구현된 좌측 영역은 다음 순서로 구성된다.

1. Breadcrumb
2. TitleBar
3. MetaChips
4. EditorToolbar
5. DocumentCanvas
6. StatusBar

구현 위치:

* `DocumentCanvas`
* `Breadcrumb`
* `TitleBar`
* `MetaChips`
* `EditorToolbar`
* `KpiCards`
* `ChannelTable`

---

# 3. Breadcrumb

## 3.1 목적

현재 문서가 어느 문서함/카테고리/유형에 속하는지 보여준다.

현재 예시:

```text
문서 > 마케팅 > 보고서 > 2024년 2분기 마케팅 성과 보고서
```

## 3.2 후속 동작 기준

* 상위 경로 항목은 클릭 가능하게 만들 수 있다.
* 마지막 항목은 현재 문서명이므로 비활성 텍스트로 표시한다.
* 경로가 길면 중간 항목을 축약한다.

---

# 4. TitleBar

## 4.1 목적

문서 제목과 즐겨찾기 액션을 제공한다.

현재 요소:

* 문서 제목
* 즐겨찾기 버튼

## 4.2 후속 구현 기준

* 편집 권한이 있으면 제목을 인라인 편집할 수 있어야 한다.
* 제목 없이 저장하는 경우 기본 제목 부여 또는 입력 요청 정책을 따른다.
* 즐겨찾기는 사용자별 상태이며 문서 자체의 공유 권한과 분리한다.

---

# 5. MetaChips

## 5.1 목적

문서의 주요 메타 정보를 빠르게 확인하고 일부 값을 수정할 수 있게 한다.

현재 표시:

* 문서 유형: 보고서
* 작성자: 김민지
* 최근 수정 시간
* 태그 목록
* 태그 추가 버튼

## 5.2 후속 구현 기준

* 문서 유형은 선택형 컨트롤로 확장한다.
* 작성자는 최초 작성자 또는 소유자와 혼동되지 않도록 라벨 정책을 정한다.
* 최근 수정 시간은 서버의 `updatedAt` 기준으로 표시한다.
* 태그 추가는 권한이 있는 사용자만 가능하다.

---

# 6. EditorToolbar

## 6.1 목적

본문 편집에 필요한 기본 서식 액션을 제공한다.

현재 버튼:

* 문단 스타일
* 글자 크기
* 굵게
* 기울임
* 밑줄
* 취소선
* 글자색
* 채우기 색
* 펜
* 정렬
* 글머리 기호
* 번호 매기기
* 체크리스트
* 표
* 이미지
* 링크
* 체크박스
* 완료 체크
* 더보기

## 6.2 UX 기준

* 아이콘 버튼은 30px 내외의 고정 크기를 유지한다.
* 툴바는 가로 스크롤 가능해야 하며 레이아웃을 밀어내지 않는다.
* 사용할 수 없는 액션은 비활성화한다.
* 기능 설명은 aria-label 또는 tooltip으로 제공한다.

## 6.3 후속 구현 기준

현재 툴바는 정적 목업이다.

실제 에디터 엔진을 붙일 때 다음이 필요하다.

* 선택 영역 상태 감지
* 현재 블록 타입 표시
* 버튼 활성/비활성 상태
* Undo/Redo와 상단 헤더 액션 연동
* 표/이미지/링크 삽입 플로우
* 키보드 단축키

---

# 7. DocumentCanvas

## 7.1 목적

문서 본문이 표시되고 편집되는 영역이다.

현재 예시 문서는 마케팅 성과 보고서이며 다음을 포함한다.

* 요약 섹션
* KPI 카드
* 채널별 성과 섹션
* 성과 테이블
* 주요 캠페인 성과 섹션

## 7.2 후속 구현 기준

* 본문은 서버의 `documents.content`를 기준으로 렌더링한다.
* AI 생성 문서도 일반 문서와 동일한 편집 표면에서 수정 가능해야 한다.
* 저장 실패 시 작성 중인 내용이 사라지지 않아야 한다.
* 자동 저장과 명시 저장 상태를 구분한다.
* 긴 문서는 캔버스 내부에서 스크롤한다.

---

# 8. StatusBar

## 8.1 목적

문서 작성 상태와 기본 통계를 보여준다.

현재 표시:

* 글자 수
* 이미지 수
* 표 수
* 페이지 수

## 8.2 후속 구현 기준

* 글자 수는 본문 기준으로 계산한다.
* 이미지/표 수는 문서 구조 파서 또는 에디터 상태에서 계산한다.
* 페이지 수는 실제 페이지 기반 편집기가 아닌 경우 예상 값으로 표시하거나 제거한다.
* 저장 상태는 상단 헤더의 저장 상태와 충돌하지 않게 정리한다.

---

# 9. 저장 및 버전 정책

## 9.1 저장

문서 수정은 다음 정책을 따른다.

* 수동 저장
* 임시 저장
* 기본 자동 저장

저장 실패 시:

* 재시도 제공
* 작성 중 내용 보존
* 사용자에게 명확한 상태 안내

## 9.2 버전

버전은 다음 경우 생성한다.

* 명시 저장
* AI 생성 결과 저장 또는 삽입 후 저장
* 버전 복원

자동 저장은 버전 기록과 분리할 수 있다.

---

# 10. 권한 기준

| 작업 | 필요 권한 |
| --- | --- |
| 문서 열람 | View |
| 제목 수정 | Edit |
| 본문 수정 | Edit |
| 태그 수정 | Edit 또는 Manage 정책 |
| 문서 유형 변경 | Edit |
| 보관/삭제 | Manage |
| 복원 | Manage |

권한이 없으면 편집 컨트롤을 숨기거나 비활성화한다.
